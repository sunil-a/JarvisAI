# Jarvis AI Assistant

## About

Jarvis AI is a personal voice assistant project built using Python. The goal is to develop an assistant that can recognize voice commands, respond using speech, and help automate everyday laptop tasks.

## Features

* Voice recognition
* Text-to-speech responses
* Personal assistant functionality
* Planned laptop and application controls

## Technologies

* Python
* SpeechRecognition
* pyttsx3
* PyAudio

## Installation

Install the required libraries:

```bash
pip install SpeechRecognition pyttsx3 pyaudio
```

## Run

```bash
python jarvis.py
```
